# Quality gate

| Field | Record |
|---|---|
| Phase | Discovery / Build / Test / Release |
| Scope | Describe the bounded change or release |
| Owner | Accountable person or role |
| Critical risks open | 0 required for Go |
| Required evidence | Links or approved references |
| Decision | Go / No-Go |
| Decision maker | Name or role |
| Follow-up | Next action and due date |

## Review prompts

- Is the scope and intended behavior unambiguous?
- Are security, accessibility, and data-quality risks addressed for this change?
- Is the rollback or recovery owner known?
- Are limitations visible to the people making the decision?
