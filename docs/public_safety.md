# Public-safety boundary

Before publishing a delivery case or a template derived from professional work:

- Recreate diagrams and examples with fictional names and synthetic data.
- Remove application exports, Solution/Flow packages, connection references, environment identifiers, URLs, user names, screenshots, and customer assets.
- Do not state production deployment, compliance, performance, or business impact without public, approved evidence.
- Keep the real project repository private; publish only recreated reference material and documented limitations.
